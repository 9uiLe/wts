# 作業ログ

## 2026-09-08: Pre-release の自動公開

入力バージョンで成果物を公開し、同じ master コミットからの重複公開を防ぐため、手動実行の Release ワークフローを追加した。正式リリース条件が未確定のため Pre-release を公開する。バージョンはビルド時に埋め込み、公開元の追跡ファイルを変更せずにバイナリ・ビルド情報・タグを一致させる。

## PR とコミットの設計根拠

wts のレビューでは、CLI の振る舞いと配布への影響を、変更の目的と検証結果に照らして判断する。このため、PR テンプレートは契約・リリース影響・コミットごとの変更内容・受け入れ条件をまとめる構成とする。検証は変更内容に応じて選び、実施結果と未検証事項を区別することで、契約がどこまで証明されているかを明確にする。

レビュー中に説明と差分を直接対応付けられるよう、変更内容はコミットハッシュ単位で示す。開発時から目的ごとにコミットを構成し、メッセージに変更内容と目的を記すことで、個々の変更を履歴から理解できるようにする。
