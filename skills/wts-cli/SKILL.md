# wts CLI

ユーザーや実行環境が指定した実行ファイルを使い、指定がなければ PATH 上の `wts` を解決します。操作前に、その実行ファイルからガイドを取得してください。

```sh
wts skills get wts-cli
```

ガイドの共通事項と依頼に対応する手順を読み、後続コマンドにも同じ実行ファイルを使用します。取得に失敗した場合は実際のエラーを報告し、操作を進めないでください。
